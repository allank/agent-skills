## Agent skills

### Issue tracker

Issues live in GitHub Issues (`allank/agent-skills`), managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout — one `CONTEXT.md` + `docs/adr/` at the repo root (created lazily as decisions get made). See `docs/agents/domain.md`.

### Adapted skills

Credit the author in the README **Credits** section (name + link) and in a `<!-- Adapted from … -->` comment under the SKILL.md H1. A missing upstream licence doesn't block adoption.
